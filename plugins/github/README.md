# GitHub

Milo packages the [official GitHub Agent plugin](https://github.com/github/github-mcp-server/tree/99d6d6503a7b2a133e2f8a595d6d0ba24b4086d3/agent-plugin). Version 0.1.0 is the Milo package version. The server runs at GitHub.

Install the plugin, open its GitHub MCP connection, and enter your GitHub token. Select the tools for the Agent. For review and CI inspection grant read access to the target repository, pull requests, checks, commit statuses, and Actions as needed.
