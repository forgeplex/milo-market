# Bitwarden

先使用已启用的 Bitwarden MCP `status` 检查状态。插件安装不代表账号已连接。
如果工具不存在，报告连接尚未配置；不要安装其他密码管理器或修改 Milo 核心。
如果状态是未登录或已锁定，请用户打开 Milo 设置 → 插件 → Bitwarden，点击“连接账户”或“重新连接”，并在专用表单中完成登录和验证。不要让用户运行 CLI、获取或填写会话密钥。不要向用户索取主密码、会话令牌或验证码到聊天中。

只有用户授权使用对应网站账号时，才按当前网站 URL 查询匹配项目。多个项目匹配时，请用户选择。
官方 MCP 会将读取结果返回给 Agent；不能声称密码对模型不可见。不要把密码、TOTP、会话令牌写入聊天、文件、记忆或日志。
自动填入凭据前核对当前 HTTPS 网站与登录项的网站地址；遇到域名不符时停止。
不要为登录任务创建、修改或删除保险库项目。只有用户明确要求相关写操作时才执行。
网站是否登录成功，以网站页面结果为准；取到凭据不代表登录成功。

首次测试使用专门的测试登录项。先确认 `status`，再按用户指定的测试网站查询，不读取其他项目。
